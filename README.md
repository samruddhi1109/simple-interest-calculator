# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Rate of interest
- Time period

## Example
Principal = 1000  
Rate = 5%  
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Output
Simple Interest = 100
